
# Pizza Sales Analysis Dashboard (Power BI)

## Project Overview
Developed an interactive Pizza Sales Analysis Dashboard in Power BI to analyze sales performance, customer ordering patterns, and business insights. The dashboard provides KPI tracking, category analysis, and product performance visualization to support data-driven decision-making.

## Key Features
- Revenue analysis and KPI monitoring
- Total orders and pizzas sold tracking
- Average order value analysis
- Orders distribution by pizza size
- Revenue analysis by pizza category
- Top 5 and Bottom 5 selling pizzas
- Orders trend analysis by day

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Data Cleaning
- Data Visualization
